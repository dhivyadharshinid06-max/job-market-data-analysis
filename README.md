# 📊 Job Market Data Analysis

An end-to-end Data Analytics project that analyzes job market data to identify hiring trends, salary patterns, company ratings, industries, and job locations. The project demonstrates the complete data analytics workflow, from data cleaning to interactive dashboard creation.

---

## 📌 Project Overview

The goal of this project is to transform raw job market data into meaningful insights that can help understand current hiring trends and employment opportunities. The project includes data cleaning, preprocessing, exploratory analysis, and dashboard development using Power BI.

---

## 🎯 Objectives

- Clean and prepare raw job market data.
- Analyze hiring trends across industries.
- Compare salary estimates.
- Identify top hiring locations.
- Explore company ratings and sectors.
- Build an interactive Power BI dashboard.

## 🧹 Data Cleaning Process

The following data cleaning steps were performed:

- Removed duplicate records.
- Handled missing values.
- Standardized text formatting.
- Corrected inconsistent values.
- Converted columns to appropriate data types.
- Prepared the dataset for visualization.
